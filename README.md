# sea_turtles
data and results: developing a machine learning model for detecting sea tutle tracks on sandy beaches


## Plan
1. Annotate mp4 files in data folder for a few objects that are not turtle tracks
2. Build an initial model, verify inference works OK
3. Add turtle tracks (these are rare, don't have data yet - season will start in a few weeks)
4. Add more annotations, refine model
